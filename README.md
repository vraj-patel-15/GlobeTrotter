GlobalTrotters

GlobalTrotters is a travel planning and expense management platform designed to help travelers organize itineraries, estimate destination costs, and share community travel plans.

Key Features

Personalized Dashboard: Track upcoming trips, monitor overall expenses, and view total trip statistics in one place.

City & Cost Exploration: Search global destinations with real-time average daily cost breakdowns and region-based cost indexes.

Community Itineraries: Browse shared travel plans from other users worldwide and copy proven itineraries directly to your account with a single click.

Trip Builder: Easily add prospective destinations to your trip agenda and estimate budget requirements beforehand.

Tech Stack

Frontend: HTML , CSS

Backend: Python 

Database: PostgreSQL
